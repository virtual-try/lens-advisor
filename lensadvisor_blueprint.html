Cart Bundling Mechanics & Front-End DOM Event API

Prescription eyewear consists of multiple line items (Frame + Base Lens + Option Upcharges + Add-ons). LensAdvisor manages bundle cohesion using three distinct cart bundling modes and exposes a client-side JavaScript API with 26 DOM event hooks.

1. Standard Bundling

All Shopify Plans

Renders Frame, Lens, and Add-ons as separate line items in the cart drawer. Quantity synchronization scripts ensure removing one item purges all associated bundle items. Underscore properties (`_productType`) hide technical metadata.

Requires custom cart block or theme script snippet.
Recommended Target

2. Native Bundling (Cart Transform)

Modern Storefronts & POS

Powered by Shopify's WebAssembly cart.transform.run API. Merges multiple bundle lines into a single displayed item (`linesMerge`) at the platform layer. Operates identically online and inside Shopify POS.

Standardizes cart UX across Online Store, POS, and Headless.

3. Single Lineitem Bundling

Shopify Plus Only

Combines frame, lens, coatings, and add-ons into a single physical cart line using Shopify Plus API access. Cannot be combined simultaneously with Native Cart Transform merging.

Restricted to enterprise Plus store installations.
