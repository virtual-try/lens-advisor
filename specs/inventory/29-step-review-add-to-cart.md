# Inventory fragment — Spec 29 (Configurator step 7: review and add to cart (nested lines))

### `add-bundle`
`packages/configurator/src/cart/add-bundle.ts` & `packages/configurator/src/cart/index.ts` — Adds a configurator bundle to the Shopify cart as nested cart lines via the Cart AJAX API (`POST /cart/add.js`). Generates `bundleId` via `crypto.randomUUID()`. Posts the frame line first with bundle properties (`_bundle_id`, `_bundle_role: "frame"`), reads the returned line `key` from the response (Self-check 1), and then posts child lines (lens, each option value with a `shopifyVariantId`, and each add-on with a `shopifyVariantId`) with `parent_id` set to that frame line key. The lens line carries `_option_ids`, `_addon_ids`, `_rx_ref`, and prescription properties (`Prescription: "Prescription on file"` when `storeRxInOrder` is false; `_rx_od`/`_rx_os`/`_rx_pd` when true, per INV-3). Zero-delta options without a variant (such as Clear tint) do not get a cart line; their ID is recorded in the lens line `_option_ids`. On any child failure (e.g. 422 sold out, 500, or network throw), rollback immediately removes the frame line via `POST /cart/change.js` with quantity 0, preventing partial bundles (Self-check 2). Exports `getCartEndpoint` respecting `window.Shopify.routes.root`, `refreshCartOrRedirect` (dispatches theme's `cart:refresh` event or navigates to `/cart`), `AddBundleError`, and `addBundle`.
**Use instead of:** Hand-crafted cart fetch calls, manual cart property building, or un-rolled-back multi-line adds.
**Added by:** spec 29.

### `review-step`
`packages/configurator/src/steps/07-review/index.tsx` & `packages/configurator/src/steps/07-review/ReviewStep.tsx` — Configurator Step 7 module exporting `{ id: "review", titleKey: "review", isComplete: () => true, isApplicable: () => true, Component: ReviewStep }`. Displays a complete itemized review of the shopper's choices: Frame (title, variant/sub, formatted price, Change button), Vision (rxType, description, Edit button), Prescription (summary without values when `storeRxInOrder` is off per INV-3; full prescription table when on; Edit button), Lens (name, description, price, Edit button), Options (selected option labels, deltas summary, total price, Edit button), and Extras (selected add-ons, price, Edit button). Edit button on Lens dispatches `GO_TO_STEP` with `stepIndex: 3` (Step 4 "Lens") while keeping the selection. Reassurance notice reminds shopper that opticians check prescriptions before manufacturing. Renders expanded `PriceSummary` itemized breakdown. Renders primary button `"Add to cart — $235.00"` where the total is strictly derived from `priceSelection` (Self-check 3, INV-4). Double-click protected (button disabled and `aria-busy` during submission). On child add failure, renders an accessible alert banner (`role="alert"`) with error message `"Couldn't add your lenses"` and a Retry button.
**Use instead of:** Custom review screens or non-standard add-to-cart buttons.
**Added by:** spec 29.
